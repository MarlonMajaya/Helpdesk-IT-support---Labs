## Help Desk Portfolio 

## 👋 Overview

This repository contains hands-on Help Desk labs demonstrating real-world troubleshooting skills for Windows 11 environments. These labs simulate common IT support tickets and document the steps used to resolve them.

Every lab is written the way a real ticket is closed: what the user reported, how the problem was investigated, what caused it, how it was fixed, and how the fix was confirmed.

## 🛠 Skills Demonstrated

- Windows 11 troubleshooting
- User account management
- Active Directory basics
- Group Policy awareness
- Networking fundamentals
- Printer and software support
- Event Viewer log analysis
- Security incident response
- Documentation and communication

## 🧾 How Each Lab Is Documented

Every lab follows the same ticket-style format:

1. **Ticket / Scenario**: what the user reported, in their own words
2. **Symptoms**: what was observed on the machine
3. **Troubleshooting Steps**: what was checked, in order, and why
4. **Root Cause**: what was actually wrong
5. **Resolution**: the fix applied
6. **Verification**: how the fix was confirmed with the user
7. **Prevention / Notes**: how to avoid a repeat, and when to escalate
